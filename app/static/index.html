// END-TO-END SYSTEM PIPELINE & DATA HYGIENE

From raw Kaggle records through cheater filtering, Polars feature engineering, and containerized deployment.

STEP 1: ANOMALY CLEANING

Filtered 1,725 anomalous/cheater rows (zero-movement kills, 100% headshot snipers with 10+ kills, impossible longest kills >1000m, extreme item hoarders). Cleaned dataset: 4,445,240 records.

STEP 2: VECTORIZED POLARS

Engineered 102 features across 4 families in 8.51 seconds. Saved to high-speed Parquet (228 MB vs 630 MB raw CSV), speeding up loading time to 0.3s.

STEP 3: GROUP VALIDATION

Strict GroupKFold on matchId (38,371 train matches, 9,592 held-out test matches). Zero match-level target leakage across folds.

// 4 DISTINCT FEATURE FAMILIES

Match-Relative (24) Within-match percentile rank, ratio to match mean, ratio to match max.
Team Aggregates (36) Teammate mean, max, min, sum across groupId for kills, distance, and boosts.
Efficiency Ratios (9) Damage/kill, kills/walk distance, heals/distance, items/distance.
Match Context (4) Match size, group count, squad size, clustered match type.
